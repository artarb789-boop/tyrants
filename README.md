# Тираны Подземья — браузерная версия

Цифровая версия настольной игры «Тираны Подземья» (Tyrants of the Underdark), собранная по русскому PnP.
2–4 игрока на одном устройстве, каждое место — человек или бот. Все 6 колод базы и дополнения
«Аберрации и нежить»: Дроу, Драконы, Элементали, Демоны, Аберрации, Нежить.

## Запуск

Картинки карт и поля — арт правообладателя, поэтому в репозитории их нет. Их нужно один раз
вырезать из своего PnP-архива:

```bash
pip install pymupdf opencv-python-headless numpy
python tools/extract_assets.py "путь/к/Tirany_Podzemya.zip"
```

После этого откройте `index.html` в браузере (можно просто двойным щелчком, сервер не нужен).

## Устройство

| Файл | Что внутри |
|---|---|
| `js/engine.js` | правила: поле, присутствие, контроль, жетоны, действия, ход, подсчёт очков |
| `js/effects.js` | эффекты всех 125 карт (ключ — название карты) |
| `js/ai.js` | эвристический бот |
| `js/ui.js` | интерфейс: настройка, поле (SVG поверх картинки), рынок, рука, окна выбора |
| `js/data_cards.js` | данные карт, извлечённые из PnP |
| `js/data_board.js` | разметка поля: 26 регионов, 41 маршрут, 140 локаций, белые отряды |
| `tools/extract_assets.py` | вырезает картинки из PnP-архива в `img/` |
| `tools/sim.py` | прогон партий ботов без интерфейса (`pip install quickjs`) |

Проверка правил прогоном ботов:

```bash
python tools/sim.py 5 2                  # 5 партий на двоих
python tools/sim.py 3 4 demons,undead    # 3 партии на четверых, выбранные колоды
```

## Трактовки правил

- Жетон контроля даёт +1 влияние в начале хода владельца; при захвате в свой ход — сразу, но не чаще раза за ход.
  ПО за полный контроль начисляются в конце хода.
- Фокусировка срабатывает, если карта того же аспекта уже сыграна раньше в этом ходу.
- Оркус и Лич возвращают на поле отряды игрока из чужих трофейных залов.
- Любой эффект карты можно пропустить.

Фанатские дополнения из PnP (Демоническая паутина, Паукообразные, Осада, Юголоты, Места Силы) пока не реализованы.
